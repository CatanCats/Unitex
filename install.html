UUnitex

Install Unitex Helper

Browsers don't let one website read another website's pages, which is how your email and bank stay private from other sites. Unitex Helper is a tiny browser extension that loads search results from Google, Bing, Brave, Mojeek, Yandex and SearXNG (including their image, video, news and shopping pages) and store searches on Amazon, eBay, Walmart, Best Buy, Kogan, Big W, JB Hi-Fi, Argos, Gumtree and other big stores, in your own browser, with your cookies, so Unitex can show them all on one page. It can't load anything else, and only Unitex pages can use it.

Download Unitex Helper (.zip)

Chrome, Edge, Brave, Opera, Vivaldi

  1. Download the zip above, right-click it and choose Extract All… (Mac: double-click it). You'll get a folder called unitex-helper.
  2. Open that folder and check you can see manifest.json, background.js and content.js in it. That's the folder to pick in step 5. (If you see another unitex-helper folder instead, you downloaded an older zip: pick the inner one.)
  3. Open chrome://extensions (Edge: edge://extensions).
  4. Turn on Developer mode (top right; in Edge it's on the left).
  5. Click Load unpacked and choose the folder that has manifest.json in it.
  6. Come back to this page and refresh. The box above turns green.

Firefox

  1. Download and unzip as above.
  2. Open about:debugging#/runtime/this-firefox and click Load Temporary Add-on….
  3. Choose the manifest.json file inside the extracted folder.

Firefox removes add-ons loaded this way when it restarts, until Unitex Helper is published on Firefox Add-ons.

"Manifest file is missing or unreadable"?

  • You picked a folder that doesn't directly contain manifest.json. Open the folder you chose: if it only contains another folder, pick that one.
  • You picked the .zip itself, or a folder still inside the zip. Extract it first (right-click → Extract All).
  • The folder is in OneDrive and its files are "online-only" (a cloud icon next to them). Right-click the folder → Always keep on this device, or extract it somewhere outside OneDrive, such as C:\Users\you\unitex-helper.
  • On a school or work computer, IT settings may block Developer mode or unpacked extensions. If the Developer mode switch is greyed out, or Chrome says extensions are blocked by your administrator, it can't be installed on that computer.

Phones

Mobile Chrome and Safari don't support extensions. On Android, Firefox, Kiwi, Yandex or Edge Canary can load extensions; on iPhone, Unitex works without the helper.

What it does, exactly

The whole extension is three short files you can read in extension/. When you search on Unitex, the page asks the helper for each engine's (or store's) result page; the helper fetches it and hands back the HTML; Unitex picks out the results and shows each one with its website and the engines that found it. Nothing is sent anywhere else.
